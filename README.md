# Foldbox Studio

3D-редактор коробки и складных буклетов A4 и A3. В редакторе можно менять размеры коробки, примерять оформление крышки, загружать изображения и PDF для буклетов и скачивать выбранный ракурс в PNG или набор ракурсов в ZIP.

[Открыть редактор](https://letrosfy.github.io/foldbox-studio/)

## Локальный запуск

Из корня проекта запустите сервер для готовой сборки.

```sh
python3 -m http.server 8000 --directory dist
```

Откройте [редактор на своём компьютере](http://localhost:8000/).

## Разработка

Код редактора, модели и оформление находятся в `src/`. Разметка и стили страницы находятся в `dist/index.html` и `dist/studio.css`. После изменения JavaScript или макетов пересоберите проект.

```sh
npm install
npm run build
```

## GitHub Pages

Сайт публикуется из корня ветки `gh-pages`. Чтобы обновить его, перенесите содержимое `dist/` вместе с `.nojekyll` в корень этой ветки, сохраните изменения коммитом и отправьте его на GitHub.
